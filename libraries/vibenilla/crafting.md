# crafting

Crafting for Minestom

## Source Code

https://github.com/vibenilla/crafting

## Installation

::: code-group

```kts [Gradle (Kotlin)]
repositories {
    maven("https://maven.skylite.gg/releases")
}

dependencies {
    implementation("rocks.minestom:crafting:2026.10.13-26.3")
}
```

```groovy [Gradle (Groovy)]
repositories {
    maven {
        url 'https://maven.skylite.gg/releases'
    }
}

dependencies {
    implementation 'rocks.minestom:crafting:2026.10.13-26.3'
}
```

```xml [Maven]
<repositories>
    <repository>
        <id>skylite</id>
        <url>https://maven.skylite.gg/releases</url>
    </repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>rocks.minestom</groupId>
        <artifactId>crafting</artifactId>
        <version>2026.10.13-26.3</version>
    </dependency>
</dependencies>
```

:::
